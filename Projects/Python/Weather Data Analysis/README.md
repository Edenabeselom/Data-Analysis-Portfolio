🎯 Overview

This report documents the systematic data extraction, transformation, and exploratory analysis of real-time meteorological data across major global cities using the OpenWeather API. The objective is to automate structured Python workflows to capture live atmospheric metrics and evaluate environmental patterns.

📈 Weather Data & Environmental Insights

The weather dataset provides a detailed comparative view of meteorological conditions, capturing temperature variations, humidity levels, and prevailing atmospheric states.

🔍 Trends and Insights

* **Temperature Variations & Trends:** Comparative evaluations highlight regional temperature trajectories, with Paris recording the highest temperature at **30.81°C** and Nairobi recording the lowest at **23.39°C**.
* **Moisture & Humidity Metrics:** Analysis of atmospheric humidity highlights Tokyo registering the highest moisture level at **84%**, corresponding with overcast conditions.
