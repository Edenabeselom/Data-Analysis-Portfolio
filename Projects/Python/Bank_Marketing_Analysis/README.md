🎯 Overview

This report documents the systematic data preparation, exploration, and visual analysis of the Bank Marketing Dataset (11,162 rows, 17 columns). The objective is to extract actionable intelligence and evaluate term deposit subscription trends using structured Python workflows.

📈 Bank Marketing & Customer Insights

The bank marketing dataset provides a comprehensive view of campaign interactions, capturing customer demographics, financial balances, and historical engagement metrics.

🔍 Trends and Insights

Target Distribution: The target variable analysis indicates a balanced split with 52.6% non-subscribers (no) and 47.4% subscribers (yes).
Demographic & Balance Spread: Box plot evaluations highlight customer age medians and account balance ranges across subscription outcomes, identifying distinct financial thresholds for high-potential leads.
Correlation Analysis: The numerical feature correlation matrix reveals underlying relationships among campaign parameters such as pdays and previous interactions.
Analytical Scalability: The established Jupyter Notebook framework serves as a robust pipeline for advanced customer segmentation and predictive campaign modeling.
